      BEFORE CASE

      台架测试

      1. 主板、CPU、临时内存与电源先裸机点亮。
      2. 用 BIOS FlashBack / BMC 更新稳定版 BIOS，确认 i5-14500 正常识别。
      3. 两块 980 PRO 更新固件并跑 SMART 长测。
      4. 关闭无限功耗 / MCE，先设 PL1 90W、PL2 125W。

      INSTALL ORDER

      最不返工的顺序

        TRUE NAS

        存储池结构

          VIBRATION

          减震与搬家

          1. 保留硬盘托架原厂胶套，螺丝贴合即可，不要过度压紧。
          2. 桌面共振明显时，在机箱脚下加 6–10mm 软木橡胶复合垫。
          3. 不要用海绵包住硬盘，也不要做软悬挂：会影响散热与背板对位。
          4. 机械盘搬运前完全关机、等待停转；整机保持直立并填充外箱。
